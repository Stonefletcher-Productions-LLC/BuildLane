          Agents

          How agents are selected

          Which coding agents write and review the code. Fletchery picks one per task from those that are on, signed in and not at a limit: cheap agents for easy tasks, strong ones for hard ones, and a reviewer from a different company than the writer. Switch an agent off and nothing new goes to it; what it is running finishes. Open a model for its scores. Sign-ins, plan or API key, and the keys themselves are in Settings > Accounts.
